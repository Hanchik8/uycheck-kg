# ГИК КР — Порядок подачи электронной заявки через portal.gik.kg и «Түндүк»
Источник: Официальный портал ОАО «ГИК» (https://gik.kg / https://portal.gik.kg).

## Пошаговая инструкция подачи заявки
Процесс подачи заявки на участие в программе «Менин үйүм» полностью цифровизирован:
1. **Онлайн-регистрация:** Гражданин регистрируется и заполняет электронную заявку на официальном портале ОАО «ГИК» (`gik.kg` / `portal.gik.kg`).
2. **Автоматическая проверка через «Түндүк»:** Данные о семейном положении, трудовом стаже, налоговых/социальных отчислениях и отсутствии зарегистрированной недвижимости проверяются автоматически через государственную систему межведомственного электронного взаимодействия **«Түндүк»**.
3. **Подтверждение согласия:** Для подтверждения личности и согласия на обработку персональных данных (включая согласие супруга или супруги) используется мобильное приложение **Balance.kg** (раздел «Государственная ипотечная компания») или инструменты идентификации «Түндүк».
4. **Оплата электронных справок:** Необходимые электронные запросы оплачиваются через мобильные кошельки и банки КР (*Элкарт Мобайл, Balance.kg, MegaPay, О!Деньги, Элсом*).
5. **Отслеживание очереди:** После одобрения заявка попадает в электронную очередь; статус проверяется в разделе «Статус заявки» на сайте `gik.kg`.
